# ごはんネット

レシピのURL、料理名、タグ、メモを保存し、料理の記録をカレンダーで振り返れる静的Webアプリです。

## データ保存について
- 保存先は閲覧中ブラウザの `localStorage` (`gohan-net-data-v1`)、カラー設定は `gohan-net-theme-v1` だけです。
- バックエンド、クラウドDB、外部API、アクセス解析、CDN、外部フォントは使用していません。
- ブラウザや端末ごとにデータは独立し、自動同期されません。
- シークレットモード、サイトデータ削除、ストレージ容量制限等により保存できない／消えることがあります。定期的にJSONファイルを保存してください。
- JSONファイルには入力したレシピ情報・調理履歴がそのまま含まれるため、バックアップの取り扱いにご注意ください。
- GitHub Pages自体へのアクセスにはGitHub側の標準的な配信ログ等が存在する場合があります。「サーバーには一切保存しない」はアプリが扱う**レシピや履歴のデータ**に対するものです。
- 別の外部レシピサイトへのリンクを開く場合は、そのサイト側の通信が発生します。
